⚡ QuickForge教师工作台功能（完整版）

一套装在老师电脑里的「AI 智慧教学工具箱」：图形界面（GUI）一键生成网页/语音/图片/视频，网站端提供学生可访问的互动页面，内置 12+ 网站模板、34 套垂类应用系统与海量教学课件资源，无需编程、无需公网，双击即用，一键发布到内网供全班手机/电脑访问。

🤖 AI 生成网页🎨 语音/图片/视频📚 知识库问答 📝 论文写作与审稿🔎 知网检索核验📥 资源本地化 🧑‍🏫 数字人开口视频🧩 模板与系统 46+🚀 一键内网建站

🧭一、三大入口，各有所长

同一个程序，三种用法：桌面窗口里点按钮、浏览器里让学生访问、资源库里直接套用现成系统。

入口是什么最适合
🖥️ 后端 GUI 界面桌面窗口（Python/Tkinter），10 个功能选项卡，点按钮即用，无需开浏览器教师本人：生成网页、配置模型、建知识库、写论文、发布网站
🌐 前端网页（网站端）程序自动发布的网站：首页门户、AI 生成/多模态、知识库问答、人设问答、审稿改稿系统等学生访问、随处可用的功能页面、在线审稿与答题
🧩 网站模板和资源「我的课件」里内置 12+ 可直接套用的网站模板、34 套垂类应用系统、精品教学课件 10000+快速搭系统：作业评测、知识库问答、留言互动、报名统计、行业管理……
💡 三者的产物都在 「我的课件」 文件夹里统一管理，可互相引用：GUI 生成的网页放进网站模板、网站端发布后学生即可访问。

🖥️二、后端 GUI 界面（10 个功能选项卡）

打开程序即出现主窗口，顶部一排选项卡即全部功能——每个都突出一个「能帮你省多少事」的亮点。

🌐 网页生成 备课神器

一句话生成教学网页：输入需求直接产出可运行的 HTML，支持常规页 / 交互采集 / 作业提交 / 网页转换 / 学情报告/ PPT 网页6 大类网页；内置 AI 与外部 AI 双通道，可附加文件。

✦ 亮点：不会代码也能 30 秒生成带交互、能收作业的网页课件

📥 资源本地化 断网可用

把任意在线网页一键下载并本地化：图片、脚本、样式全部打包到本地，离线也能打开演示。

✦ 亮点：机房断外网也能上课，课件永不失效

🎨 多模态生成 素材工厂

文字转语音（6 种音色）、声音克隆（录一段即得你的音色）、AI 生成图片、AI 生成视频、文本朗读。

✦ 亮点：PPT/PDF 上传即转视频——自动逐字稿 + 配音 + 带字幕视频

💬 AI 对话 备课助手

智能问答，可附带文档/图片分析；支持语音输入与播报，实现"语音对话"。

✦ 亮点：把资料丢给它，问答/润色/分析一步到位

📚 本地知识库（RAG） 专属私教

把 pdf/docx/pptx 等资料建成自己的知识库，AI 基于资料回答并标注引用来源；支持混合检索、重排序、知识图谱预览、全量/增量更新。

✦ 亮点：AI 回答"有据可查"，不瞎编

📝 论文写作 / 改稿 科研加速

填写学科、研究问题、创新点等建档，设定"AI 不得改动"的合规边界，一键生成大纲或初稿，无缝衔接审稿润色。

✦ 亮点：从空白到成稿的完整流程，合规红线可控

🔎 知网检索与参考文献 文献管家

上传文章由大模型自动提取关键词/参考文献，按检索词在知网批量检索、下载、AI 核验，自动生成 GB/T 7714 参考文献列表。

✦ 亮点：参考文献格式全自动，核验防"编造文献"

✅ AI 审稿润色 文章医生

选择学术化表达、逻辑连贯、规范引用等要点，AI 自动改稿；支持基于知识库的事实/数据核验与终稿复审。

✦ 亮点：投稿前多一次 AI 质检

⚙️ AI 模型配置 一处配全局

集中配置文本 / 图像 / 视频 / 视觉理解四类大模型的地址、密钥与模型，保存即生效并写入 config.ini，全程序共用。

✦ 亮点：换模型只改一处，所有功能立刻跟随

🚀 网站发布 一键上线

一键启动内网网站服务，把「我的课件」发布为浏览器/手机可访问的站点，自动生成 HTTP / HTTPS 地址与二维码。

✦ 亮点：全班扫码即访问，无需服务器与域名

🌐三、前端网页（网站端）

程序启动即自动发布网站。这些页面既是给学生用的，也是给自己用的在线工作台。

页面功能亮点
🏠 首页（index.html）网站门户：汇总入口、展示你的资源与模板，内容可自行修改。
🌐 网页生成与转换（deepseek.html）在线生成教学网页；内置提示词模板库（按学科筛选）与 AI 逆向工程（从现有网页反推出风格/描述/模板）。
🎨 多模态内容生成（quickforgeai.html）文生文 / 文生图 / 文生视频 / 图生视频 / 讲稿转视频（上传 PPT/PDF 自动配音合成） / 图生图 / 文生网页 / 文生语音 / 语音克隆 + AI 对话，全部网页化。
📚 知识库管理与问答（kb.html）在线管理任务知识库、知识图谱预览，数字人人设问答门户。
🎓 任务知识库与人设问答（/taskkb/）按「教师 + 活动」隔离的任务级知识库；AI 以自定义数字人身份回答学生提问，支持语音输入、通话模式、自动朗读，可合并全局库与 IMA 云端库。
🤖 智能审稿和改稿系统（/review/）论文全流程工作台：建档 → 知网检索下载 → 多源事实核验（知识库/互联网/知网原文/文献）→ 四引擎改稿（发表级润色 / 技能驱动 / OpenClaw / WorkBuddy）→ 知识库问答弹窗。
☁️ 学生答案词云对学生提交的文本答案做分词与词频统计，一键生成全班答案词云，热点与共性一目了然。
⚙️ AI 模型配置（ai_config.html）与 GUI 同步的网页版四类模型配置，保存即生效。
🔒 涉及视觉识别、拍照、摄像头的网页（如拍照留言、图片识别）浏览器要求使用 HTTPS 链接访问；程序已内置自签名证书，首次访问点"高级 → 继续访问"即可。

🧑‍🏫六、数字人开口视频对话功能（新增）

让静态形象「开口说话」：上传一张照片或选择内置数字人，输入文字/语音即可生成口型同步的开口视频；更支持「视频对话」模式——数字人实时聆听、理解并开口回应，像面对面交流。

🧑 数字人形象生成 一张照即助教

上传一张正面照一键生成专属数字人；内置教师 / 讲解员 / 卡通等多种风格形象可选，免建模、免拍摄。

✦ 亮点：几分钟得到一位「不会累的数字助教」

🗣️ 文字 / 语音驱动口型 口型同步

输入讲稿或语音，AI 自动匹配口型、表情与语气，输出口型精准同步的开口说话视频，支持多语言与音色。

✦ 亮点：PPT/讲稿一键变「老师亲自讲」的视频

🎥 视频对话（实时开口） 面对面答疑

数字人实时聆听用户语音 / 文字，理解后即时开口回复，形成「你问我答」的面对面对话视频，可结合知识库作答。

✦ 亮点：把答疑、招生宣讲做成可反复播放的「真人视频」

🎬 多场景模板 即套即用

内置微课讲解、课前导入、课后答疑、招生宣讲、政策解读、新闻播报等模板，选模板填内容即得成片。

✦ 亮点：教学短视频批量产出，省去录制剪辑
能力说明
🖼️ 形象来源单张照片生成 / 内置形象库 / 导入已有视频形象；生成后可保存复用。
🎙️ 驱动方式文字讲稿、语音文件、实时麦克风三种驱动；实时对话走语音识别 + 大模型理解 + 口型合成。
💡 知识支撑对话可接入本地知识库 / IMA 云端库，让数字人「言之有物」，按学校资料作答。
📤 产出形式开口说话短视频（MP4）/ 实时对话视频流，可直接嵌入课件、网站发布页或扫码观看。
🧑‍🏫 数字人功能由多模态视频生成模型驱动（口型 / 表情 / 语音合成），与「多模态生成」「本地知识库」选项卡联动：先建好知识库，再让数字人基于它开口答疑，效果最佳。
